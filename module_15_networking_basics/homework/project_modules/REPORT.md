## Улучшения

В данном проекте мы реализовали API для управления комнатами. В процессе работы над проектом мы стремились повысить уровень зрелости нашего API, следуя принципам REST и практикам проектирования. 

### Уровень зрелости

- **Текущий уровень зрелости:** 2 модели Ричардсона


### Изменения

1. **Структура URL и название маршрутов:**
   - Изменены маршруты на более RESTful:
     - `/rooms` для создания и получения списка комнат
     - `/rooms/<int:id>` для обновления и удаления комнаты

2. **Добавление методов для обновления и удаления:**
     - `PUT /rooms/<id>` для обновления комнаты по её ID.
     - `DELETE /rooms/<id>` для удаления комнаты по её ID.
   - Позволяет клиентам управлять ресурсами более гибко, что улучшает функциональность API.

   - **Обоснование:** Ссылки облегчают навигацию по API и позволяют клиентам динамически находить другие доступные действия с ресурсами.

3. **Обработка ошибок:**
   - Улучшены сообщения об ошибках и коды статуса:
     - Код 400 для отсутствия имени комнаты.
     - Код 404 для попыток обновления или удаления несуществующей комнаты.
   - Это делает API более информативным и удобным для отладки.

### Заключение

Внесенные изменения улучшили качество нашего API. 
Это не только улучшает удобство использования, но и упрощает дальнейшее развитие и поддержку проекта. 
Данные изменения были оформлены в Postman-коллекции для тестирования улучшенного API.
